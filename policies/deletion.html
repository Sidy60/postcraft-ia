Suppression d’un compte et des données

Cette procédure concerne les applications qui permettent de créer un compte utilisateur.

Comment demander la suppression

  1. Envoyez un e-mail à sidymohameddiallo5@gmail.com.
  2. Indiquez le nom de l’application et l’adresse e-mail associée au compte, si applicable.
  3. Écrivez clairement : « Je demande la suppression de mon compte et des données associées ».
  4. Une vérification raisonnable de votre identité peut être demandée.

Traitement

La demande sera examinée et les données personnelles associées au compte seront supprimées, sauf celles qui doivent être conservées pour respecter une obligation légale, résoudre un litige, prévenir la fraude ou assurer la sécurité. Les données conservées pour ces motifs seront limitées et protégées. Les sauvegardes techniques peuvent être supprimées selon leur cycle normal de rotation.

Applications sans compte

Si une application ne permet pas de créer de compte et ne conserve pas de données personnelles permettant de vous identifier, la suppression de compte peut ne pas s’appliquer. Vous pouvez néanmoins nous contacter pour toute question relative aux données.

À vérifier avant publication : si une application permet la création de comptes, elle doit aussi proposer une option de suppression facilement accessible dans l’application. Ne présentez pas cette page comme preuve d’une fonction de suppression qui n’existe pas réellement.
