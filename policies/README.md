# Pages juridiques — Sidy Mohamed Diallo

Pages communes : accueil, confidentialité, conditions, assistance et suppression des données.

**Important :** ce contenu est un modèle commun. Pour chaque application Google Play, la politique de confidentialité doit être vérifiée et adaptée à la collecte réelle de données, aux SDK, aux prestataires, aux permissions et aux durées de conservation. La déclaration « Sécurité des données » doit correspondre au code. Si l'application permet la création de comptes, elle doit offrir une suppression de compte dans l'application et une procédure web externe.

Ce dossier est autonome et n'altère pas le code de Postcraft IA.
